# 10 Stacks Research — Homepage Mockup

A hand-coded, static HTML/CSS homepage concept for the 10 Stacks Research
wellness/supplement brand, built to match the client's reference design
(cream canvas, black + periwinkle two-tone headlines, clinical glassware
imagery, minimal uppercase nav).

This is a front-end concept to demonstrate design direction and quality
before the full WordPress/WooCommerce build.

- `index.html` — the full page (single file, no build step, no dependencies)

Open `index.html` in any browser, or view the live version via GitHub Pages.
